# Feature Ideas

## Playback & Audio
- Sleep timer — stop playback after N minutes (common radio feature)
- Recording snippets — save a short clip of what's playing to a file
- Equalizer / bass boost using AVAudioEngine

## Station Discovery
- [x] Browse by country or genre with dedicated browsing UI (radio-browser.info supports `bycountry`, `bytag`)
- "Similar stations" when you right-click a station
- Recently played history

## Now Playing
- Song history log — ICY metadata changes as tracks change; log them with timestamps
- Last.fm scrobbling
- Share now-playing via clipboard or system share sheet

## Library / Presets
- Station folders/groups for organizing the library
- Import/export library as JSON (already done)
- iCloud sync for the library across Macs

## UI / UX
- Mini player mode (just artwork + controls, very compact)
- Menu bar "now playing" text showing current track title from ICY metadata
- [x] Keyboard shortcuts for preset slots (⌘⇧1–⌘⇧6 in Playback menu, 1–6 bare on buttons)
- Global hotkey to play/pause from anywhere (system-wide shortcut)

## System Integration
- Now Playing system widget (Control Center / lock screen metadata)
- Handoff support to continue listening on iPhone (requires iOS companion)
